论文深度解剖

先检查 PDF 文字与版面质量，再用中文回答研究问题，并把证据定位到原页。

能力说明

多栏、表格和扫描页会自动选择解析策略。完整中文语义解读需要配置本地或获准的模型；未配置时使用中文快速定位模式，原文证据保留原语言，避免把机器翻译冒充原文。

固定中文输出

为什么很多论文只有题录？

摘要是否可用取决于出版方和元数据源。题录仍包含标题、作者、年份、DOI 等信息，但不适合直接做深度解读。开启“只看有摘要”，或通过 DOI、学校订阅和开放获取页面取得原文。

中文关键词为什么会影响英文结果？

英文数据库可能接受中文输入，但召回通常更窄。请把中文研究问题保留在左侧，并在右侧填写英文同义词、缩写和领域术语；系统会将英文检索式用于英文优先的数据源。

PDF 怎样得到可靠中文回答？

系统先做版面提取，再进行语义分析。数字版 PDF 优先使用 Markdown 多栏解析；扫描页需要 Tesseract OCR。配置本地模型后才能获得完整中文语义解读；任何关键数字都应回到页码、图表和补充材料核验。

如何判断实验是否充分？

逐项检查数据代表性、基线公平性、消融或敏感性分析、统计不确定性、外部验证和结论边界。缺一项不一定否定论文，但必须记录为待核验项。

复现实验最低清单

记录代码版本、运行环境、数据来源与许可、预处理、随机种子、超参数、硬件、评价脚本和失败日志。把原始数据与生成结果分开保存。

组会沟通模板

本周完成了什么；哪条证据改变了原判断；当前阻塞是什么；需要导师决定什么；下周准备交付什么。尽量附表格、图或可运行代码，而不是只描述过程。

知网与 Google Scholar 如何使用？

受许可和接口政策限制，平台不会自动抓取。请在原站合法检索并导出 BibTeX、RIS、EndNote、RefMan 或 NBIB，再从文献雷达导入统一证据层。

怎样安全使用 AI？

不要上传含个人、患者、未公开专利或保密数据的内容到远程模型。把生成内容当待核验草稿；引用、数字、政策适用性和创新性判断必须检查原始来源。
