# LatticeScholar 用户指南

本指南面向第一次使用科研工作台的高校教师、研究生和本科生。目标不是解释所有技术名词，而是帮助你完成一条可复查的科研流程。

## 启动方式

- **桌面版（推荐）**：从 [GitHub Releases](https://github.com/CBarran498/LatticeScholar/releases) 下载对应平台的压缩包，解压后双击 `LatticeScholar`（Windows 上是 `LatticeScholar.exe`），浏览器自动打开，无需安装 Python。
- **源码运行**：安装 Python 3.9+，执行 `pip install -e .` 后运行 `latticescholar`。详见 [本地安装指南](LOCAL_SETUP.md)。

## 首次登录

启动后浏览器会打开邮箱登录页。输入你的邮箱地址，点击"获取验证码"，6 位验证码会发送到你的邮箱中。请检查收件箱（以及垃圾邮件文件夹），输入验证码即可登录。

首次使用的邮箱会自动注册。用 `LATTICE_ADMIN_EMAILS` 中的邮箱登录为管理员（Pro 权益），其他邮箱默认 Free 用户（含 7 天 Pro 试用）。管理员可在"系统管理"中为其他用户赠送 Pro。

## 最短上手路径

1. 在“科研项目”建立一个课题，写清研究对象、场景、约束和希望验证的关系。
2. 在“文献雷达”分别填写中文研究主题和英文检索式，记录数据源、年份和筛选条件。
3. 优先查看“有摘要”结果；仅题录记录可收藏，但不应直接用于深度结论。
4. 取得合法 PDF 后进入“论文深度解剖”，先看解析质量、页数和章节覆盖，再看中文回答。
5. 把关键论文、政策、分析和研究假设保存到同一个项目。
6. 在“科研任务台”把下一步变成一周内可交付、可检查的任务。

## 文献雷达

### 中文与英文为什么分开

中文输入会更容易命中中文题录和包含中文元数据的记录；英文优先数据库通常使用英文领域术语召回更稳定。平台不会偷偷调用模型翻译检索式，因此建议同时填写：

- 中文主题：完整描述你的研究问题；
- 英文检索式：核心概念、同义词、缩写和技术名词。

英文检索式会优先用于 Semantic Scholar、OpenAlex、arXiv、PubMed 和 Web of Science。中文、English 和中英混合结果在界面中独立分组。

### 为什么会出现“仅题录”

题录通常仍有标题、作者、年份、期刊、DOI 等信息，但当前元数据源没有返回摘要。它不等于论文原文没有摘要。你可以：

- 开启“只看有摘要”；
- 增加 OpenAlex、Semantic Scholar 或 PubMed 等来源；
- 通过 DOI、出版社、机构订阅或开放仓储合法获取原文；
- 从知网、Google Scholar 或 Web of Science 导出 BibTeX/RIS 后导入。

不要绕过登录、订阅、验证码或站点反爬规则。

## PDF 与中文解读

PDF 处理分为两个不同阶段：

1. 版面提取：默认读取文字层、坐标、多栏和分页；扫描页需先完成 OCR。
2. 语义解读：回答痛点、创新增量、实验充分性和回看清单。

v0.9 默认 `core` 引擎使用 PDFPlumber 输出带页码的版面阅读流，并用 pypdf 兜底。这套默认依赖保持宽松许可，适合带文字层的论文。若确需 PyMuPDF4LLM、PyMuPDF 与 Tesseract OCR，可安装 `.[advanced-pdf]` 并设置 `LATTICE_PDF_ENGINE=pymupdf`；启用前必须阅读第三方 AGPL/商业许可说明。完整中文语义解读需要配置本地模型或明确允许的远程模型。未配置模型时，系统使用中文规则定位模式，解释为中文，证据引文保留原语言。

提交后，页面会隐藏输入表单并只保留四问中文回答。每问先给直接结论，再按 3—6 条要点说明；页码显示在对应要点下，英文原句仅在“核对原文依据”中展开。需要更换论文或问题时点击“重新分析论文”。

任何模式都无法保证对任意 PDF 100% 正确。以下内容必须回原文核验：公式、复杂表格、图片文字、脚注、补充材料、统计数字、参考文献和作者没有明确披露的信息。

## 实验充分性检查

- 数据或样本是否有清晰来源、纳入标准和代表性；
- 基线是否公平，训练数据和预算是否可比；
- 是否有消融、敏感性或稳健性分析；
- 是否报告不确定性、置信区间或适当的统计检验；
- 是否有外部、跨中心、跨时间或真实场景验证；
- 结论是否超出实验对象、指标和数据范围。

## Idea Lab：导入你已有的工作

你可以手动描述前期工作，也可以直接拖入 PDF、Word、PowerPoint、Excel、ODT、TXT、Markdown、RTF、HTML、CSV、JSON、BibTeX、RIS、NBIB、LaTeX 或 Jupyter Notebook。每次最多 5 份，单份不超过 12 MB。旧版 `.doc/.ppt/.xls` 需先在 Office/WPS 中另存为新格式。

1. 上传后先查看文件名、字符数、解析警告和文字预览；
2. 扫描版 PDF 未提取到文字时，请先 OCR，或在完成许可评估后启用可选高级引擎；复杂公式、图片和格式必须回原文核验；
3. 手动补充失败经验、数据权限、设备、时间和伦理约束，不要只上传论文成果；
4. 生成时，系统把手动说明和已选文件合并，再与已选论文、政策证据一起形成可证伪方向；
5. 远程模型开启时，只会按路由设置发送合并后的必要文本。不要上传患者身份、未公开专利核心、审稿材料或保密数据。

## 复现最低清单

- 代码仓库和提交版本；
- 操作系统、依赖锁定和硬件；
- 数据来源、许可、版本和划分；
- 预处理、随机种子、超参数；
- 训练与评价命令；
- 失败日志、原始输出和生成图表的脚本。

## 隐私与科研伦理

- 不要把患者信息、个人信息、未公开专利、审稿材料或保密数据发送到远程模型；
- 引用、数字、政策适用性和创新性必须核验原始来源；
- AI 生成内容是待核验草稿，不是作者、导师或伦理委员会的替代品；
- 公开交流功能上线前必须具备举报、审核、身份与数据删除机制。
