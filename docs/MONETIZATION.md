# LatticeScholar 开源模式说明

## 定位

LatticeScholar 是 Apache-2.0 完全开源项目。所有功能对所有登录用户免费开放，不区分会员与非会员，不设使用次数限制。

## 用户角色

| 角色 | 说明 |
|---|---|
| 管理员 | `LATTICE_ADMIN_EMAILS` 中的邮箱登录后自动获得管理员角色，可进行政策审核等管理操作 |
| 普通用户 | 其他邮箱登录后为普通用户，拥有全部功能权限 |
| 社区版 | `LATTICE_AUTH_MODE=open` 时无需登录，所有功能可用 |

## 功能矩阵

| 能力 | 是否可用 |
|---|---|
| 全部文献数据源 | 是（需自备 API Key） |
| BibTeX / RIS / NBIB 导入 | 是 |
| 深度分析 / Idea Lab | 是（需配置模型） |
| 证据库 | 无限制 |
| 政策发现与审核 | 是（管理员审核） |
| 多模型 AI 路由 | 是 |

## 成本控制建议

- 检索结果默认缓存 24 小时，减少重复 API 调用；
- 规则模式不调用模型，永远保留为免费回退；
- 深度分析限制输入字符和最大输出 Token，避免无边界发送；
- 用户自行承担模型 API 调用成本（通过 BYOK 方式）。

## 开源协议

Apache-2.0 许可证，允许自由使用、修改和分发。
