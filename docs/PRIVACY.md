# 隐私与安全模型

## 本机验证时的默认行为

- 服务只监听 `127.0.0.1`；
- 默认开源 Community 模式无需账号；无遥测、无广告、无第三方分析脚本；
- 收藏与缓存写入本地 SQLite；
- 上传 PDF 只在内存中解析，不由应用保存；
- 未配置 LLM 时不会向模型服务发送文本；
- 环境变量配置的远程 LLM 仍需显式设置 `LATTICE_ALLOW_REMOTE_LLM=true`；在模型控制台主动保存 BYOK 密钥和确认数据边界视为当前账号的明确授权。

## 托管账号模式

`LATTICE_AUTH_MODE=accounts` 会保存规范化邮箱、签名会话所需的用户 ID、每日用量、套餐状态和管理员赠权。验证码只保存 HMAC 摘要并在 10 分钟后过期；开发模式下的验证码预览日志不得用于生产。证据库按用户 ID 隔离。

启用 Stripe 后，应用会向 Stripe 发送邮箱、内部用户 ID 与订阅元数据，不接触支付卡号；支付卡数据在 Stripe 托管页面处理。使用 SMTP 会把目标邮箱与验证码邮件交给所配置的邮件服务商。

## 会离开本机的数据

选择外部学术数据源后，检索词会发送到对应来源。配置远程模型并明确允许后，论文文本、已有工作、研究目标、已选论文摘要和政策摘要可能发送到模型提供方。

使用任一已连接模型时，双语检索式任务会发送主题、领域提示和可选项目问题；论文解剖会发送经长度限制的证据窗口；科研研讨最多发送当前项目 12 条证据的有限摘要/笔记/分析要点和 8 条已选政策。不会发送其他项目证据、账号邮箱、订阅状态或其他厂商 API Key。可选的模型用户标识是内部数字标识，不包含邮箱。

网页 BYOK 密钥在服务端使用 Fernet 加密后存入 `provider_credentials`，按账号 ID 隔离。读取配置只返回末四位提示；删除服务商配置会删除对应密文。个人本机首次运行会在 `.data/credential.key` 生成仅本机可读的密钥；生产部署必须设置稳定的 `LATTICE_CREDENTIAL_ENCRYPTION_KEY` 并交给密钥管理器。丢失加密密钥后，已有密文无法恢复，只能删除并重新配置。

模型用量日志只保存提供方、模型、任务、输入/输出/缓存/推理 Token、耗时和时间，不保存提示、论文正文、用户问题或回答。完整字段和任务边界见 [DeepSeek 集成指南](DEEPSEEK_INTEGRATION.md)。

## 不应输入的内容

- 国家秘密、工作秘密或校内明确限制材料；
- 未公开专利的关键技术细节；
- 可识别患者、受试者、学生或员工的信息；
- 受数据使用协议限制的原始数据；
- 评审中的稿件、基金申请或他人未公开成果（除非获得明确授权）。

## 部署建议

- 个人电脑保持默认 `127.0.0.1`，不要直接改为 `0.0.0.0` 暴露到网络；
- 机构或官方托管使用 `compose.production.yaml` 提供邮箱账号、TLS 与反向代理；边缘层还需增加 IP 限流、防机器人、访问日志治理、备份与恢复演练；
- 平台运营方的 API Key 只放环境变量或密钥管理器，不写入仓库；用户 BYOK 只通过模型控制台提交；
- 不在 GitHub Issue、截图、邮件、普通日志或聊天中收集任何模型 API Key；
- 定期更新依赖并运行安全扫描；
- 删除 `.data/` 前先导出或备份需要保留的证据。

生产部署的具体边界与操作见 [官方托管服务部署方案](PRIVATE_DEPLOYMENT.md)。
